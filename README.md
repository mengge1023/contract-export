# Contract Export

一个用于批量生成学员合同的 Codex Skill。它读取学员信息表与 Word 合同模板，校验学员数据，生成逐人合同、压缩包、异常名单和内部生成清单。

## 核心规则

- 合同条款以用户提供的 `.docx` 模板为唯一权威，只填充模板中已有的个人信息槽位。
- 合同序号必须直接使用学员表“序号”列的原始值，禁止按本批有效记录从 `001` 重新编号。
- 即使分批导出或跳过异常记录，也必须保留每位学员在源表中的序号。
- 纯数字序号在文件名中可以补足三位，例如源表序号 `11` 对应 `011`，但数值不得改变。
- 缺少序号或序号重复的记录列入异常，不生成合同。
- 默认只生成本地文件，不上传合同平台、不发送、不催办，也不联系学员。

## 输入

- 学员信息表，优先使用 `.xlsx`
- Word 合同模板 `.docx`

规范化后的学员记录包含：

```json
{
  "excelRow": 2,
  "serialNumber": 11,
  "realName": "张三",
  "wechatName": "示例微信名",
  "phone": "13800000000",
  "idNumber": "110101199001010000"
}
```

其中 `serialNumber` 必须来自学员表的序号列，不能临时生成。

## 输出

- 单份合同目录
- 合同 ZIP 压缩包
- 异常名单
- 内部生成清单

默认合同文件名：

```text
序号_微信名_真实姓名_手机号后四位_合同.docx
```

## 安装

将本仓库复制或克隆到 Codex skills 目录：

```text
~/.codex/skills/contract-export
```

重新打开 Codex 会话后，可以通过 `$contract-export` 调用。

## 批量脚本

在确认模板槽位并准备好规范化 JSON 后运行：

```bash
python scripts/fill_contracts.py \
  --template template.docx \
  --students students.json \
  --output-dir outputs/contracts \
  --zip outputs/contracts.zip \
  --exceptions outputs/exceptions.txt
```

脚本默认填写模板中的 `乙方：` 和 `乙方身份证号码：`。如果模板槽位不同，应先检查模板，并通过参数指定准确前缀。

## 数据校验

下列情况默认列入异常：

- 序号、真实姓名、微信名、手机号或身份证号为空
- 序号重复
- 手机号重复
- 身份证号重复或格式异常
- 完全重复记录

微信名重复不会自动排除，文件名会使用真实姓名和手机号后四位消歧。

## 隐私与边界

身份证号和手机号属于敏感信息。不要把真实学员表、生成合同、异常文件或包含个人信息的 JSON 提交到公开仓库。本仓库只应保存技能说明与通用脚本。
